Welcome to the official repository of Yerim's Safe Zone
This is a deeply personal portfolio and creative web space built entirely by Sumaya Muhammad Qazamel, a 17-year-old developer, writer, and creator from Egypt. This project was crafted to be more than just a standard portfolio; it is an interactive digital room reflecting a unique blend of frontend development, visual aesthetics, and personal storytelling.
<img width="1366" height="768" alt="image" src="https://github.com/user-attachments/assets/44d1a1c3-1b76-4651-9b1a-cf1d6da61d51" />
In a digital world full of standard templates and corporate layouts, Yerim's Safe Zone serves as an artistic escape. It merges clean, modern code with a cozy, dark-themed aesthetic. Every corner of the website is designed to tell a story, invite interaction, and showcase technical skills alongside creative passion.
Features a dark, immersive color palette, custom cursor styling, and smooth responsive layouts tailored for various screen sizes.
Dynamic background effects that bring the web page to life.
Integrated background audio player (Soft noise and YouTube audio integration) to create a relaxed, immersive atmosphere while browsing.
A JavaScript-powered quote generator button that delivers random, inspiring thoughts with a single click.
A narrative section chronicling Sumaya's growthfrom early childhood curiosity and rebelling against the ordinary, to creative exploration and the official launch of the Renrei Project.
